Prepare their directories after every change to config.organizations: on a machine that mounts each
organization's root, as the storage administrator, run

  huron adm provision-orgs --dry-run   # what it would do
  huron adm provision-orgs             # or --emit-script for roots only root may write
  huron adm verify-mounts              # every organization must be ok
{{- else }}
No organizations are declared (unmanaged mode): platform admins create them with `huron create org`,
under the CLI's mount_prefix, which huron adm provision-orgs marks.
{{- end }}
