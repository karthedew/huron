# Huron documentation site

The Starlight site the web serves at `/docs`, readable without signing in. Run these commands from
`web/docs-site/`:

| Command | Does |
| --- | --- |
| `npm ci` | Install the pinned Astro and Starlight. |
| `npm run build` | Sync the guides, build the static site into `dist/` (base `/docs`) with its Pagefind index, and check every internal link. |
| `npm run dev` | Sync once, then serve the site with live reload at http://localhost:4321/docs/. Run `npm run sync` again after editing `docs/`. |
| `npm run preview` | Serve the built `dist/` at http://localhost:4321/docs/. |
| `npm run sync` | Regenerate the concept, guide and administration pages from `docs/` only. |
| `npm test` | Unit tests of the sync and post-build scripts. |

Where each page comes from:

- `src/content/docs/concepts/`, `src/content/docs/guides/` and `src/content/docs/administration/`
  are generated by `scripts/sync.mjs` from the files its `SOURCES` lists: `docs/concepts/*.md` and
  `docs/architecture.md` (Concepts), `docs/user-guide.md` and `docs/api-errors.md` (Guides), and
  `docs/operator.md` (Administration, one page per `##` section). They are not committed: edit the
  files under `docs/`. A relative link resolves against the directory of its file, as on GitHub
  (`../user-guide.md` from `docs/concepts/`). Links between those files become `/docs/…` URLs, and
  a link to a heading that does not exist fails the sync. The sync reads `../../docs` from this
  directory, or the directory `HURON_DOCS_DIR` names.
- `src/content/docs/reference/cli/` is generated by `scripts/cli_reference.py` at the repository
  root from the CLI's help and its `LAYOUT` panels, and is committed so reviews show CLI changes.
  After changing a command, run `uv run python scripts/cli_reference.py` from the repository root;
  the gate's `--check` fails until you do.
- `src/content/docs/index.mdx` and `getting-started.md` are hand-written and link into the rest.
- The Components diagram in `docs/architecture.md` uses the SVG files in `public/diagrams/`.
  The compact version keeps labels readable on narrow screens. Both versions follow the site's
  theme and support forced colors. They render without browser scripts or external services.

Write documentation with `.claude/skills/asd-ste100/SKILL.md`. From the repository root, run
`uv run python scripts/ste_check.py` to check the prose. Run `npm test` and `npm run build` here
to check the sync scripts and the links of the built site.

The policy the web sends for `/docs/**` (`web/src/lib/server/docs.ts`) adds the `'sha256-…'`
source of each inline script of the page served, computed from the built file when it is served,
and `'wasm-unsafe-eval'` (Pagefind's search runs WebAssembly) to `script-src`. Its `style-src` has
`'unsafe-inline'`, because Starlight and Expressive Code set `style` attributes. `npm run build`
prints how many distinct inline scripts the pages hold.
